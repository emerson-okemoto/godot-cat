# Feira de Rua com Gatos Famintos

## 1. Proposta do jogo

"Feira de Rua com Gatos Famintos" é um jogo 2D em que a pessoa controla uma feirante e precisa proteger a barraca de alimentos dos gatos que tentam alcançá-la. A defesa é feita com uma vassoura, que assusta os gatos e faz com que eles fujam temporariamente, sem eliminá-los.

O objetivo é proteger a barraca até o fim do tempo. Se a barraca receber cinco ataques antes disso, a partida termina em derrota.
